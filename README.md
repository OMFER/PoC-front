# 💳 App Pagos - Development Console

Un dashboard administrativo moderno construido para gestionar, monitorizar y descargar los diferentes *builds* y *assets* (Proyectos) del ciclo de vida de despliegue de la aplicación de pagos.

## ✨ Características Principales

* **Historial de Builds:** Visualización del estado de los despliegues (Success, Building, Failed).
* **Gestión de Assets:** Modal interactivo para descargar artefactos específicos (APK, AAB, ZIP) por versión.
* **Filtrado por Componentes:** Navegación por pestañas para separar Pry, clientes y scripts.
* **Diseño Modular:** Interfaz limpia basada en componentes y Atomic Design.

## 🚀 Tecnologías (Tech Stack)

* **Core:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
* **Iconos:** [Lucide React](https://lucide.dev/)

## 📦 Requisitos Previos

Asegúrate de tener instalado en tu entorno local:
* [Node.js](https://nodejs.org/) (v18.0.0 o superior recomendada)
* npm, yarn o pnpm
